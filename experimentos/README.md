# Zona de experimentación

Esta carpeta contiene variantes de trabajo. Nada de lo que se escriba aquí modifica por sí mismo los originales ni se convierte automáticamente en versión estable.

## Reglas

- Cada variante tiene un identificador único.
- Se indica la versión de referencia de la que parte.
- Se documentan cambios exactos y su motivo.
- Se separan hipótesis, observaciones, resultados y conclusiones.
- Se conserva el registro de pruebas, incluidos resultados negativos.
- Ninguna variante se declara superior sin evaluación suficiente.
- Una variante solo pasa a `main` mediante revisión y aprobación.

## Primera batería propuesta

Las secuencias 123, 132, 213, 231, 312 y 321, y las secuencias con repetición como 1321 y 2132, son candidatas de prueba, no resultados validados. Antes de probarlas habrá que definir qué significa cada cifra según el texto íntegro de las leyes.
