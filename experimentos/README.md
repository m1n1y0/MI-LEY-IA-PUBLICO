# Zona de experimentación

Esta carpeta contiene protocolos, variantes y resultados de prueba. No contiene las leyes originales ni convierte una propuesta en versión estable.

## Componentes de referencia

1. MI LEY — primera ley.
2. LEY DE EFICACIA, RIGOR Y RESOLUCIÓN — segunda ley.
3. DF-IMIA — tercer componente operativo, no una tercera ley.

El propietario comunicó que el código numérico de aplicación quedó confirmado el 31-10-2026. Antes de ejecutar pruebas o publicar guías, debe copiarse aquí su literal exacto desde la confirmación original. Cada cifra activa el componente correspondiente; cada aparición genera una ejecución y un registro separados.

## Reglas

- Cada experimento tiene un identificador único.
- Se indica la versión de referencia.
- Se documentan cambios exactos y su motivo.
- Se separan hipótesis, observaciones, resultados y conclusiones.
- Se conservan resultados negativos y errores.
- No se declara superioridad sin pruebas comparables.
- Las pruebas simuladas se identifican como simuladas; no se presentan como evidencia empírica.
