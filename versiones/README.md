# Versiones aprobadas

Esta carpeta documenta versiones que hayan superado una evaluación y recibido aprobación expresa.

Una versión no entra aquí solo por estar terminada o por parecer prometedora. Debe incluir:

- identificador y fecha;
- referencia exacta de las leyes y documentos utilizados;
- cambios incorporados;
- pruebas y resultados reproducibles;
- limitaciones conocidas;
- decisión y aprobación.

Hasta que exista una primera versión experimental evaluada y aprobada, esta carpeta contiene únicamente estas reglas.
