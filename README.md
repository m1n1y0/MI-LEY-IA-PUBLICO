Repositorio para conservar las dos leyes originales y DF-IMIA como tercer componente operativo, y documentar su aplicación y comprobación.

## Arquitectura vigente: componentes 1–2–3

1. **MI LEY** — primera ley.
2. **LEY DE EFICACIA, RIGOR Y RESOLUCIÓN** — segunda ley.
3. **DF-IMIA — Diagrama de Flujo Idioma Máquina IA** — tercer componente operativo de aplicación y comprobación; no es una tercera ley.

Los números identifican los tres componentes. La secuencia de aplicación debe respetar el código numérico confirmado por el propietario. Cada cifra activa el componente correspondiente; cada aparición, incluidas las repeticiones, debe generar su propia ejecución y registro.

El literal exacto del código no está reproducido en este registro; no se sustituye por 123, 1321, 3231 ni otra conjetura. Las referencias antiguas 1321 y 3231 se conservan como antecedentes hasta cotejarlas con la confirmación literal.

El **prompt escueto queda excluido**: fue una prueba puntual, no es ley, componente vigente ni documento del sistema definitivo.

## Flujo de trabajo

1. Preservar los textos fuente originales sin cambios.
2. Leer el código confirmado y recorrer sus cifras en el orden exacto.
3. Para cada cifra, generar una guía de comprobación derivada del texto auténtico del componente.
4. Registrar entrada, acción, evidencia, resultado, error y corrección.
5. Repetir la auditoría cuando haya una corrección.
6. No declarar autenticidad ni eficacia demostrada sin evidencia suficiente.
7. Integrar cambios en la referencia estable solo con aprobación expresa.
